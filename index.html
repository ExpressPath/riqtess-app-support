Join and install with TestFlight Get TestFlight from the App Store
  1. Install Apple TestFlight from the App Store if it is not already on your iPhone.
  2. Open this page in Safari and tap “Join and install with TestFlight”.
  3. Accept the beta invitation in TestFlight, then tap Install or Update.

The newest release appears after Apple finishes processing and approves it for external beta testing. iPhone does not install a raw app file directly from an ordinary website; this page uses Apple’s TestFlight installation flow.

Troubleshooting and common questions

How do I set up my card?

On the Connect screen, open your card editor, choose one of the available designs, add the account links you want to show, and save. Card designs are selected from the catalog; free-form layout editing is not available.

Nearby sharing does not start

Keep both supported iPhones unlocked with riqtess open in the foreground. Turn on Bluetooth and allow the requested nearby permissions when prompted, then bring the phones close and try the card gesture again.

An account link opens the wrong place

Check that the destination app is installed and that the saved value is the intended username or profile link. Some services only support opening their app or search screen for certain account types.

QR screenshot import is unavailable

Select one clear QR-code screenshot from Photos. If no items appear, review riqtess photo access in iOS Settings and return to the picker to refresh the library.

Request help

If the steps above do not solve the issue, use the support form. Including the app version, iOS version, device model, steps to reproduce, and what you expected versus what happened helps us investigate.

Privacy reminder: the issue tracker is public. Describe the problem without posting personal account details, QR screenshots, passwords, verification codes, or precise location. You can also read how riqtess handles information in the privacy policy.
